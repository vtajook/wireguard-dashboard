اتصال ربات به پنل

با کلید API، ربات شما می‌تواند مستقیم کاربر بسازد، تمدید کند و لینک و کانفیگ بگیرد. هزینه‌ها مثل همین پنل از کیف پول شما کم می‌شود.

کلید فعلی: —

Header on every request: X-Agent-Key: YOUR_KEY   Base: 

GET    /api/agent/me                      → balance, prices, servers (ifaces), months
GET    /api/agent/peers?q=NAME&page=1         → your users
GET    /api/agent/peer/by-name/NAME           → one user (status, expires_at, used, link)
GET    /api/agent/peer/ID                     → one user
POST   /api/agent/peers                       → create
       {"name":"ali_1","months":1,"data_gb":0,"iface_id":1,"start_on_first_use":true}
       {"name":"test_1","test":true}          → free test account
       ← {"ok":true,"id":12,"link":"https://…","cost":…,"balance":…}
POST   /api/agent/peer/ID/renew               → {"months":1,"data_gb":50}
POST   /api/agent/peer/ID/toggle              → {"enable":false}
POST   /api/agent/peer/ID/topup               → volume users: {"data_gb":5,"months":0} (adds, keeps usage)
POST   /api/agent/peers/bulk_delete           → {"ids":[1,2,3]}
POST   /api/agent/peers/delete_expired        → {"dry_run":true} counts, {} deletes
POST   /api/agent/peer/ID/rotate              → new link + keys (old config stops) ← {"link":"…"}
DELETE /api/agent/peer/ID
GET    /api/agent/peer/ID/config              → WireGuard .conf text

Errors: {"ok":false,"error":"low_balance","detail":"…"} (HTTP 4xx).
