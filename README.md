**وایرگارد داشبورد** — پنل فارسی/انگلیسی مدیریت سرور وایرگارد برای فروش و مدیریت هزاران کاربر، با پنل نمایندگی، کیف پول، API ربات و کنترل تک‌کاربره.

## چرا وایرگارد داشبورد؟

<div dir="rtl" align="right">

این پنل برای فروش واقعی و سرورهای پرکاربر ساخته شده. چیزهایی که آن را متفاوت می‌کند:

| | |
|---|---|
| 🤝 <b>پنل نمایندگی کامل</b> | کیف پول، قیمت ماهانه و گیگی، تست رایگان، دفتر تراکنش، API و کلید اختصاصی برای ربات هر نماینده |
| ⚡ <b>سرعت با هزاران کاربر</b> | جستجو، فیلتر و صفحه‌بندی سمت سرور؛ صفحهٔ کاربران با ۲۷۰۰+ کاربر روی یک اینترفیس در کسری از ثانیه باز می‌شود و هر بار فقط چند کیلوبایت داده می‌گیرد |
| 🌐 <b>اینترفیس‌های ۴۰۰۰ کاربره</b> | زیرشبکهٔ /20 (حدود ۴۰۹۶ IP) برای هر اینترفیس و تغییر اندازهٔ زیرشبکهٔ اینترفیس موجود بدون قطع کاربران |
| 📊 <b>مصرف دقیق</b> | حساب مصرف درست کاربران (بدون شمارش تکراری)، ترافیک روزانه / ماهانه / کل سرور با نمودار ۳۰ روزه |
| 📱 <b>تک‌کاربره واقعی</b> | تشخیص استفادهٔ هم‌زمان یک کانفیگ روی چند دستگاه و قطع خودکار با جریمهٔ پلکانی |
| 🔄 <b>آپدیت خودکار از داخل پنل</b> | Update Center با بکاپ کد، بررسی، ری‌استارت امن و برگشت خودکار در صورت خطا؛ صفحه بعد از ری‌استارت خودش برمی‌گردد |
| 🗄 <b>بکاپ ساعتی تا ماهانه</b> | بکاپ خودکار با ارسال به تلگرام و نگه‌داشتن تعداد دلخواه |
| 🚀 <b>بهینه‌سازی شبکه</b> | تنظیم خودکار RPS، UDP GRO و حذف conntrack پورت‌های وایرگارد برای مصرف CPU کمتر روی سرورهای شلوغ |
| 🇮🇷 <b>فارسی کامل</b> | همهٔ صفحه‌ها، پیام‌ها و پنجره‌ها فارسی/انگلیسی با یک دکمه |
| 🧹 <b>ابزارهای روزمره</b> | حذف منقضی‌ها با یک کلیک، دامنهٔ تحویل کانفیگ جدا از دامنهٔ پنل برای هر اینترفیس، دکمه‌های اسم‌دار با تأیید قبل از کارهای حساس |

</div>

## نصب

<div dir="rtl" align="right">

روی سرور تازهٔ Ubuntu/Debian با کاربر root این یک خط را بزنید. همه‌چیز خودکار نصب می‌شود (پکیج‌ها، پنل در <code>/opt/WG_Panel</code>، محیط پایتون، کلیدهای امنیتی، سرویس <code>wg-panel</code> و IP forwarding) و در پایان آدرس ورود و توکن ثبت‌نام اولین ادمین نمایش داده می‌شود:

</div>

```
bash <(curl -fsSL https://raw.githubusercontent.com/vtajook/wireguard-dashboard/main/install.sh)
```

<div dir="rtl" align="right">

- پورت پیش‌فرض پنل <b>۵۰۸۱</b> است. برای پورت دیگر: <code>PANEL_PORT=2053 bash &lt;(curl -fsSL …/install.sh)</code>
- بعد از نصب: <code>http://IP:5081/register</code> ← ساخت ادمین با توکن ثبت‌نام ← ساخت اینترفیس از صفحهٔ کاربران ← تنظیم دامنهٔ کانفیگ در <b>تنظیمات ← اینترفیس ← اندپوینت کلاینت</b> ← فعال کردن HTTPS در <b>تنظیمات ← پنل</b>.
- <b>آپدیت:</b> از داخل پنل ← <b>Update Center</b>. کاربران قطع نمی‌شوند، قبل از آپدیت بکاپ کد گرفته می‌شود و در صورت خطا خودکار برمی‌گردد. اجرای دوبارهٔ دستور نصب روی پنل نصب‌شده هم فقط کد را آپدیت می‌کند؛ دیتابیس، <code>.env</code> و کانفیگ‌ها دست نمی‌خورند.

</div>

## امکانات

<div dir="rtl" align="right">

### کاربران
- ساخت تکی و گروهی، ویرایش، فعال/غیرفعال، حذف، حذف گروهی و <b>حذف همهٔ منقضی‌های یک اینترفیس</b> با یک دکمه (قبلش کپی دیتابیس گرفته می‌شود)
- محدودیت حجم و زمان، شروع زمان از اولین اتصال، کاربر نامحدود
- لینک اختصاصی هر کاربر (صفحهٔ ساب با QR، دانلود کانفیگ، حجم و زمان باقی‌مانده)، تغییر لینک و کلید
- جستجو، فیلتر (آنلاین، فعال، نزدیک سقف، مسدود، چندکاربره) و مرتب‌سازی <b>سمت سرور</b>؛ صفحهٔ کاربران با چند هزار کاربر هم سریع باز می‌شود
- همهٔ دکمه‌ها اسم دارند و کارهای حساس قبل از اجرا تأیید می‌گیرند

### تک‌کاربره (هر کانفیگ = یک دستگاه)
- تشخیص استفادهٔ هم‌زمان یک کانفیگ روی چند دستگاه و قطع موقت با جریمهٔ پلکانی
- برچسب «چندکاربره» روی کاربر، امکان بخشیدن و تنظیمات کامل

### پنل نمایندگی
- ورود جدا برای هر نماینده (فارسی)، فقط کاربران خودش را می‌بیند
- کیف پول پیش‌پرداخت با شارژ توسط ادمین و دفتر کامل تراکنش‌ها
- قیمت ماهانه، قیمت هر گیگ و قیمت ماه اضافه برای کاربران حجمی
- ساخت، تست رایگان، تمدید، افزودن حجم/زمان، تغییر لینک، فعال/غیرفعال، حذف، حذف گروهی و حذف منقضی‌ها
- اینترفیس‌های مجاز و سقف تعداد کاربر برای هر نماینده
- <b>API و کلید اختصاصی</b> تا نماینده ربات خودش را وصل کند
- ورود ادمین به پنل هر نماینده و قطع/وصل همهٔ کاربران یک نماینده

### اینترفیس‌ها
- ساخت اینترفیس با تنظیم خودکار Forward و NAT، فعال/غیرفعال، حذف
- تغییر اندازهٔ زیرشبکه (مثلاً /20 برای هزاران کاربر) بدون قطع کاربران
- دامنه/IP تحویل کانفیگ برای هر اینترفیس (مثلاً دامنهٔ تانل، جدا از دامنهٔ پنل)

### داشبورد و گزارش
- وضعیت سرور، CPU، RAM، دیسک، شبکه و کاربران آنلاین
- <b>ترافیک کاربران</b>: امروز، دیروز، ۷ روز، این ماه، ماه قبل، کل و نمودار ۳۰ روزه
- لاگ پنل، لاگ هر کاربر، مرکز عیب‌یابی و تعمیر خودکار موارد امن

### بکاپ و امنیت
- بکاپ کامل و بکاپ خودکار <b>ساعتی تا ماهانه</b> با ارسال به تلگرام
- بازگردانی بکاپ با پیش‌نمایش محتوا
- ورود دو مرحله‌ای (TOTP)، محافظت در برابر حملهٔ ورود و درخواست‌های مشکوک، کنترل ترافیک (مسدودسازی دامنه/IP/کشور برای کاربران)

### سایر
- رابط <b>فارسی و انگلیسی</b> با یک دکمه در منوی کناری
- اشتراک چندلوکیشنی (یک مشتری با چند کانفیگ)
- ربات تلگرام مدیریت و اعلان‌ها
- بهینه‌سازی خودکار شبکه برای سرورهای پرکاربر (RPS، UDP GRO، حذف conntrack برای پورت‌های وایرگارد)
- API کامل برای اتصال ربات فروش
